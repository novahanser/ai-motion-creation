# 像素画面

## 1. 规格

- 先定画幅、设计网格、整数放大倍率、帧率和调色板。用同一套网格画图形、遮罩和小字。
- 例如 1920×1080 可用 480×270 的工作合成，每格放大 4 倍。目标尺寸装不下整数倍时，用裁切或留边处理。
- 几何和界面按点画。照片或生成素材先排比例，再压到网格和已经设定的调色板。

## 2. 字和动画

- 小字从成片尺寸检查。用容易辨认的像素字形，按用途选留文字层或用点阵静帧。
- 用定格关键帧控制逐帧姿势。按音乐定步长时，先用 `每拍帧数 = 帧率 × 60 / BPM` 计算各拍的准确时刻，再对每个时刻取整。
- 用换色表改变亮度，保留界面原色。入场可按行、块或与中心的距离更新点，检查进出场方向是否一致。

## 3. AE 实现

- 像素层在小合成里排，放大用整倍数并保持整像素对齐。试用草图品质时，渲染设置选择当前图层品质，同时用单帧确认没有变成双线性插值。
- 编辑用形状层、中继器、时间重映射和定格关键帧。置换效果只希望挪整像素时，做一张有标记的测试图核对实际偏移。
- 点阵与矢量混合时分开预合成，避免同一个全局模糊影响文字和像素边缘。

## 4. 自查

- 在输出分辨率下检查格边、文字、对称图标和画幅边角。
- 查看透明边和内部纯色是否落在调色板内。
- 对齐一组重音与逐格切换，检查切在半格的取景变化或丢掉的一帧。
