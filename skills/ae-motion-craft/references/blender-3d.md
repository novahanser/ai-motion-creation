# Blender 与 AE

## 1. 开始前

- 两边用同一帧率、帧号和画幅。决定哪些层要透明、哪些只用来遮挡、色彩在哪边统一。
- 常规画面按项目约定管理色彩。把 RGB 当数值通道读取时，选能保持通道数值的输出设置，用测试条检查一次。
- 测节奏可以先降尺寸和采样。需要比较清晰度、透明边和压色时，按交付尺寸渲。

## 2. 搭场景

- 用几何节点从集合挑实例，按空间距离控制分布与密度。圆盘内均匀撒点时，半径用 `R × sqrt(u)`，其中 `u` 在 0 到 1 之间均匀取样。
- 要保持一个大形清楚时，限制散件占画面的面积。用几个机位检查实例的外延和遮挡，再增加数量。
- 组合修改器时一层处理一个问题。弯曲前补足网格段数；细分、线框和加厚的顺序会改变轮廓与渲染成本。
- 要让平面件在空间带出层次，可用透明贴图和自发光材质，在相机侧放深度不同的层。焦点落在需要看清的表面上。
- 为外部模型记录资源页、文件和使用范围。

## 3. 材质与分版

- **平涂：** 自发光便于保持颜色。需要假明暗时，把相机空间法线映到色带。色带用阶梯或平滑插值决定边缘软硬。
- **金属与玻璃：** 先用简洁环境测试高光、粗糙度和暗部。需要透明背景时保留照明和反射，单独控制相机看到的背景。
- **分版：** 把灰度明暗写进一个通道，把附加遮罩写进另一个通道，仍用渲染 Alpha 保存轮廓。拆版时用遮罩乘原 Alpha，保留抗锯齿覆盖。`split_plates.py` 默认读红通道作明暗、绿通道作遮罩。
- `bl_materials.py` 提供可导入的材质构造函数和合成测试场景。先在代表性镜头确认明暗与轮廓，再统一修改场景里的材质。

## 4. 相机

- 把可编辑关键帧放在运动起止、节拍和机位切换附近。位移、视线转动和滚转分开测量。
- 用父空物体添加短促推进或滚转，原相机保留连续轨迹。在相机上已有手工编辑时，先比较曲线再改。
- 多机位用时间轴标记管理切换。切换前后速度没有直接可比性，统计时标出切点。
- 透视镜头里，同样的世界位移可能因景深读成不同的屏幕速度。核对相机位移后，再用画面尺寸或投影点测视觉变化。

## 5. 动态模糊

- 决定哪些动作响应快门并保留清晰标注。用小段比较带模糊与清晰两份，特别看切点和透明边。
- `bl_shutter.py` 可按节拍和相机旋转速度打快门键。修改曲线或帧率后重新导出核对。
- 需要在 AE 里控制同一镜头的模糊强度时，保留对齐的清晰版和模糊版。`blur_cover.py` 根据相机运动数据生成叠加量。

## 6. 渲染

- 先在短帧段确定输出格式、采样和 Alpha，再按机位或用途渲染序列。
- 工程副本写入独立输出目录。检查续渲是否跳过已有帧，是否仍沿用上一版的采样、尺寸或色彩设置。
- 修改局部时记录重渲范围，比较首尾与未改段。体积、折射、时序效果对引擎和采样敏感时，先做单帧与短序列。

## 7. 进入 AE

- 灰度合成可以先把几份渲染叠好，再统一映到暗、中、亮三档。给需要保持本色的文字独立层。用 `stack_preview.py` 试叠后，在目标工程里对照一帧。
- 需要二维件穿过三维物体时，把二维件的前后部分分别放在渲染上方和下方，用局部遮罩确定互穿位置。
- 需要跟相机时，用 `bl_track.py` 导出投影位置和外接框。合成中同时核对位置、滚转和切换帧。
- 输入是数据文件或表达式时，用最终渲染入口先试。界面渲染与命令行结果不一致时，可以把必要的数据写进工程属性或关键帧。

## 8. 造型预览

- 同一造型用正视、侧视和最终镜头对照轮廓。先从主镜头确认主体可读，再添小件。
- 透明贴图作为近、中、远景时，先核对画幅内遮挡，再排景深。需要循环的结构留出可移动范围。

## 9. 修改已有场景

- 先查要改的集合、材质、相机和依赖。调速后复核场景覆盖范围、实例时序和快门键。
- 改修改器前按镜头查看哪些物体最靠近视线，修完再看剪影。需要提升细分时，先比较面积、轮廓和单帧渲染用时。
- 说是只改几何或材质时，比较前后相机曲线、渲染尺寸和帧范围，确认时序一致。

## 10. 验证

- 同一帧对照引擎输出和 AE 合成，看遮挡、色彩、颗粒和透明边。
- 按几何投影量逐帧位移，按时间标记分镜头统计。小样里看到突跳时，区分相机切换和物体跳变。
- 比较同一层的两版图可以记录 Alpha 的重合率、质心变化和亮度差，复核差距最大的帧。

## 11. 排查

- 重渲了部分帧后，在 AE 里重新读取序列，必要时刷新缓存。
- 连续位移平滑但画面仍跳时，分别检查比例变化、滚转、拍点取整和分层合成的帧偏移。
- 图层裁切、路径转义和命令选项按当前软件环境检查。命令路径含空格时用引号。

## 12. 脚本

Blender 脚本用 `blender -b scene.blend --python scripts/bl_xxx.py -- 参数` 运行。会修改工程的命令用 `--save copy.blend` 另存。`bl_common.py` 提供共用的命令参数、相机和动画曲线处理。

| 脚本 | 用途 |
|---|---|
| `bl_inspect.py` | 读工程、相机、修改器、集合、曲线和实例分布 |
| `bl_who_blocks.py` | 用网格射线识别最先挡到镜头的物体 |
| `bl_screen_motion.py` | 用几何投影估计画面逐帧位移 |
| `bl_camera_motion.py` | 导出相机逐帧位移、视线和滚转 |
| `bl_track.py` | 向 AE 提供投影位置、尺寸、距离等数据 |
| `bl_curves.py` | 导出、比较动画曲线，检查过冲和密集键 |
| `bl_keys.py` | 建立贝塞尔运动、节拍推进和父级控制 |
| `bl_shutter.py` | 给节拍和转头处设置快门键 |
| `bl_render.py` | 多机位、分层、帧段或序列渲染 |
| `bl_modifiers.py` | 检查和修改几何、细分、开关及渲染耗时 |
| `bl_extend.py` | 以可配置的节拍对齐方式延长动画 |
| `bl_materials.py` | 构造材质和渲染测试场景 |

普通工具用 `python -I scripts/脚本.py 参数` 运行。图像处理需要 NumPy、OpenCV 或 Pillow，视频工具使用 FFmpeg。FFmpeg 不在命令路径里时可设 `FFMPEG_DIR`。`seqio.py` 提供序列帧号、图像和字体的共用函数。

| 脚本 | 用途 |
|---|---|
| `stack_preview.py` | 预览灰度叠层与三色映射 |
| `split_plates.py` | 将通道数据拆成主版与遮罩 |
| `blur_cover.py` | 按相机运动数据生成模糊叠加量 |
| `alpha_over.py` | 按 Alpha 合成对齐的序列 |
| `compare_layers.py` | 比较两版序列的轮廓、位置和亮度 |
| `silhouette.py` | 从单色背景中生成剪影 |
| `seq_tools.py` | 序列预览、接段和无损解帧 |
| `model_sources.py` | 查询模型、记录每个资源的来源和许可 |
