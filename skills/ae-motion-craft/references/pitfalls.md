# AE 排错

| 现象 | 先检查 |
|---|---|
| 导入后序列变成静帧 | 确认按序列导入，重新核对素材解释和帧率 |
| 图层位置或叠法变了 | 导入器是否还原三维开关、混合模式、调整层、轨道遮罩与空间切线 |
| 一帧的改变不见了 | 取样时间、入出点和成片帧率；指定帧号取帧 |
| 改了素材仍渲出旧画面 | 重新读取素材及缓存，用一个短段复核 |
| 像素边缘变软 | 放大倍数、整像素对齐、图层与渲染品质有没有改成插值 |
| 蒙版边缘跑出调色板 | 边缘的透明度、预乘解释和输出位深 |
| 置换图没有读到效果 | 把生成置换图的层预合成，核对置换所读的源 |
| 暗部的叠加效果变化 | 工作空间、线性混合和色阶 |
| 导出与界面不同 | 用目标入口渲一帧，检查表达到数据的引用、字体和插件 |
| 转场露边 | 放大取景或在底层补边，复核模糊作用范围 |

## 处理方式

- 先在副本做最小复现。记录软件版本、素材解释、工程位深和导入方式，逐项对照。
- 按颜色或像素比较时用无损帧。查看需要比较的通道，区分位深转换抖动和真正的内容差异。
- 脚本修改后检查表达式错误，同时渲一两个关键帧。有时一个导入请求成功后仍需手工核对开关。

## 命令行渲染

使用 AE 随附的 `aerender`。先用当前版本的帮助核对选项和输出模块。示例工程、合成和输出文件按实际工作替换：

```text
aerender -project "scene.aep" -comp "Main" -s 0 -e 24 -output "preview.avi"
```

- 共享 AE 会话里的工程先保持原状。命令行任务使用独立进程和副本。
- 等日志和实际帧数都显示完成。检查素材、字体、插件、帧范围和色彩，再送长片。
- 有外部表达式数据时，用界面和命令行渲相同的一帧。不同就用有完整数据的入口，或先把必要的数据写入工程。
