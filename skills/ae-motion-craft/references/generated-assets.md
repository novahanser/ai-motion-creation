# 生成素材

## 1. 定规格和输入

- 先说明用途、画幅、构图、色数、透明通道与交付尺寸，挑选合适的输入素材。
- 对反复使用的元素，写出要保持的比例、轮廓、配色和纹理。保留一张合适的小样作为后续生成的外观参照。
- 试样先看结构，再放大查文字、边缘和透明。几何框线、图标、小字或要求精确的运动可用矢量和程序化方式处理。

## 2. 控制和整理

- 主体被拉伸时，在输入四周补出目标画幅，指定主体占画面的比例。多物体布局不稳定时，可以分开生成再按版式合成。
- 检查实际 Alpha 通道。带半透明边时，分别压在深底和浅底上查看；手工修整溢色或羽化。
- 像素素材先按格处理，再量调色板。重复出现的部件用同样的格点和颜色映射。
- 存输出和能重现的制作参数；记录交付图层的文件名、用途和尺寸。

## 3. 逐格和三维应用

- 序列先选择关键姿势，再补中间格。拼在同一图上的格子间距不齐时，逐块识别边界并统一锚点。
- 用同一机位和画幅预览贴图、剪影或背景。透明贴图可做平面层，照明、遮挡和景深交给三维场景。
- 需要保持文字、连续几何或逐帧投影精确时，把这些层从生成画面拆开，回到 AE 或 Blender 重新渲染。
