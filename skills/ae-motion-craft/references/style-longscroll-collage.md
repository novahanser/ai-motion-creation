# 长卷拼贴

## 1. 画布与坐标

- 把素材摆在一张比画幅宽的合成中。先用水平线或网格组织阅读顺序，在画布边缘留出取景和转场的余量。
- 设取景中心为 `(cx, cy)`、缩放倍数为 `s`，屏幕中心为 `(W/2, H/2)`。不旋转时，世界坐标 `(x, y)` 的屏幕位置为 `((x-cx)*s+W/2, (y-cy)*s+H/2)`。
- 区分画布内容和屏幕叠层。标题、页码或界面提示需要固定时，放到画布合成之外。

## 2. 运动

- 先编镜头表，写每个镜头的起止位置、缩放、停留时长和视觉重点。需要硬切到下一处时，用定格关键帧。
- 连续移动用少量可编辑的关键帧。短促位移或缩放可分到父级空对象，关掉父级的附加动画就能核对连续轨迹。
- 用剪影、擦除、分步显隐或局部缩放引入下一件内容。先定事件需要的拍点，再调帧数和停留。
- 对于在世界和屏幕之间切换的对象，先确保切换帧的位置和比例一致。可在一个画面上重叠两份元素，交接时只显示其中一份。

## 3. 颜色和版式

- 优先用少量底色和强调色组织信息。给相邻镜头各选一帧测色，避免全屏处理改变局部强调色。
- 在静态内容多的地方留空。高密度的段落保留可读轴线或重复标记，引导视线。
- 纹理需随素材移动时，把它放进素材的预合成。居中或屏幕固定的纹理另放一层。

## 4. AE 实现

1. 主合成放音频、章节标记和背景。
2. 长画布预合成放世界空间的素材和局部动作。在主合成中用位置和缩放模拟取景。
3. 把固定界面、字幕与全局调整层单独组织。打开塌陷变换、改变预合成尺寸或缩放后，重新检查遮挡和混合结果。
4. 大批类似元素可脚本生成。给每层固定名称、画布坐标和入出点，详见 [工程结构](project-structures.md#6-用脚本搭建和编辑)。

## 5. 验证

- 从每个镜头的首尾取帧，看画布边缘、清晰度、取景中心和遮挡顺序。
- 对比滑动前后同一素材的世界坐标。位置误差随相机运动变化时，先查坐标换算和锚点。
- 检查需要固定的叠层有没有随画布漂移，检查快速底色切换和单帧变化。
