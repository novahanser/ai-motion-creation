# 逐帧比对与验证

## 1. 对齐输入

1. 记录两份画面的尺寸、帧率、时间基、起点、色彩和 Alpha 解释。
2. 按帧对齐封闭的变化区间。比较标题进场或切点时，保留事件前后的帧。
3. 量色使用无损图像或直接读取像素，统一 RGB 解码。若输入含有压缩，先估计同类静态区域的噪声水平。

## 2. 分开相机和图层动作

- 找一处贯穿镜头的刚性形状来估计相机移动。用多个不共线的点拟合平移、缩放和旋转。重复纹理和对称图形会产生错误配准，再用其他点核对。
- 把同一块世界空间裁切在两份结果中取出来比较。相机已经运动时，屏幕上同一个矩形可能并未指向同一区域。
- 用同一个检测方法量两份输入。例如比较轮廓用 Alpha 面积与质心，比较圆形用拟合半径，比较条形用截面和端点。

## 3. 验证工程输出

1. 在工程副本中选正常帧、切点和效果变化明显的帧。对变帧率输入先确认源时间戳。
2. 按输出时间基取帧。额外的时间偏移会在阈值动画、定格切换或运动模糊中造成差异。
3. 先看整体对齐，再做差值图。分别记录形状、颜色、遮挡或时间问题。
4. 如编码、抖动或随机效果导致同一工程两次渲染不同，先画差值分布，再判断是否需要逐像素一致。

## 4. 拆层定位

- 固定底层和时间，分别渲调整层打开和关闭的帧。依次改变一项效果或参数，查看差值来自哪一层。
- 位置型参数要按图层尺寸核对。预设放在新画幅中时，检查可能保存为绝对像素的点坐标。
- 在副本用相同素材做一个已知结果的测试，再用同一套量法检验效果。多种做法都能解释结果时，记录仍然缺少的证据。

## 5. 比较与交接

- 用同帧号的并排图或差值图展示前后版本。以色块内部、轮廓、切点和字体为重点。
- 交付说明写清测了哪一段、哪些差异允许、哪些地方还需验证。
