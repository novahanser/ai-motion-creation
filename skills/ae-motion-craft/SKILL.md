# AE 动效制作

## 开工顺序

1. **定输出。** 写清时长、分辨率、帧率、色彩设置和交付格式。需要可编辑工程时，先定哪些字、曲线和效果要留在工程里。
2. **排时间。** 主合成先放音频和段落标记，再标小节、重音、人声和切点。用最终交付帧率换算时刻。切换点前后各渲几帧，听画面变化落在哪一拍。
3. **搭骨架。** 排版为主时按段落拆预合成；镜头已定时用素材加调整层；有三维时把相机和渲染层分开管理。先做一个代表性镜头，确认结构好改再批量搭建。
4. **做动作和质感。** 关键帧先定进、停、出，再调速度。控制层负责整组动作，局部动作留在各图层。纹理、颜色和模糊在各自负责的层上处理。
5. **渲染验证。** 检查变化落在哪一帧、调色板有没有跑色、边缘有没有漏底、文字能不能读。快速闪烁和高反差切换需要单独检查。
6. **收集交付。** 在整理副本上收集素材，移到新目录重新打开，核对音频、字体、插件和若干渲染帧。

## 快速检查

- **动作收不住：** 查看最后几帧的位移和速度。把动作在下一次重音前收完，或提前给它独立的停顿。
- **整幅画面很顿：** 先比较相机逐帧的位移与角度。把连续运镜和短促的冲量分到不同控制层。
- **颜色不统一：** 灰度叠层先对明暗，再用自己的调色板映射；在最终输出上检查色值。
- **叠层边缘有亮圈：** 核对直通与预乘 Alpha。用深浅两种底色分别看边缘。
- **文字和画面不同步：** 对齐可见的第一帧，检查透明度、时间重映射、帧率转换和音频延迟。
- **接手已有工程：** 先确认当前打开的版本、合成和未保存的编辑。保留原工程，在已有时间线上只改需要的段落。

## 随附脚本

在 Blender 中运行的脚本及普通 Python 工具都在 [scripts/](scripts/)。按 [脚本说明](references/blender-3d.md#12-脚本) 选择工具，根据脚本顶部的用法传入自己的输入与输出路径。修改 Blender 工程的脚本使用 `--save` 另存。
