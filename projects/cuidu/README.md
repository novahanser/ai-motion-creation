# 《翠杜》提示词与工作流

本项目整理了《翠杜》的视频生成提示词和 ComfyUI 工作流模板。

## 下载

- [下载原始压缩包](翠杜.zip)
- [从 GitHub Release 下载](https://github.com/novahanser/ai-motion-creation/releases/download/cuidu-project-20261115/CuiDu_Prompts_Workflows.zip)

两个下载入口的压缩包内容相同，包含：

- 一份 H3 各镜头提示词文档，以及一份 Seedance 分镜提示词文档。
- 四组 MiniMax H3 工作流模板，共七份 ComfyUI JSON：三组结构视频参考模板和一组首尾帧循环模板。
- 工作流使用说明，涵盖输入、运行环境与模型等准备事项。

## 使用前

压缩包中不包含图片、视频、音频素材或模型。使用工作流时需自行准备参考素材、兼容的 ComfyUI、对应节点和模型；各模板的具体要求见压缩包内的使用说明。提示词文档保留了当时的本地路径记录，换设备使用时需要按实际位置调整。
