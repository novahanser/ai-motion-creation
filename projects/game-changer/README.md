# GAME CHANGER：AE 图层版说明

这是《GAME CHANGER》动态设计小样的 After Effects 图层版。工程将部分界面、文字和动效整理为可编辑的 AE 图层，同时保留部分 PNG 序列素材。

## 工程与文件

- [下载 AE 工程压缩包](GAME_CHANGER_AE_layered.zip)：包含收集后的工程、素材和报告。
- [从 GitHub Release 下载](https://github.com/novahanser/ai-motion-creation/releases/download/game-changer-ae-layered/GAME_CHANGER_AE_layered.zip)：与仓库内的压缩包内容相同。
- 压缩包不包含单独导出的成片视频。
- `GAME_CHANGER_AE_图层版.aep`：压缩包中的 AE 工程。
- [制作记录](制作记录.md)：工程的搭建方法和 AE 注意事项；记录中提到的本地脚本不在压缩包内。

解压后的工程文件夹内包含 `GAME_CHANGER_AE_图层版.aep`、`(素材)/` 和 `GAME_CHANGER_AE_图层版 报告.txt`。收集报告记录素材共 58 项、6,493 个文件；连同工程和报告共 6,495 个文件。

## 打开与渲染

1. 完整解压工程包，保留工程与 `(素材)` 文件夹之间的相对位置。
2. 在 After Effects 中打开 `GAME_CHANGER_AE_图层版.aep`，检查素材链接；如有缺失，可在解压后的 `(素材)` 文件夹中重新定位。
3. 成片合成为 `GAME_CHANGER_成片`：1920 × 1080、30 fps、21.4 秒，共 642 帧，工程为 16 位。
4. 点阵合成以 480 × 270 制作，再放大 400%。火星、吸气框、沉入的地图、最后一格的画面与界面，以及片名光晕源等放大后的点阵层，使用「草图」品质以保持像素边缘清晰。
5. 渲染设置中的「品质」使用「当前设置」；若强制使用「最佳」品质，点阵层可能被插值而变模糊。

工程使用 AE 自带效果。字体未随工程包提供：整理报告记录两处不显示的文字层会引用 Dogica Pixel，并说明缺失时不影响画面；在其他设备上打开时仍可检查字体提示和表达式。

## 可编辑的画面与动效

### 最后一格的画面

最后一格的画面按内容拆成火的底、机甲和天、火苗、人物、头发、披风六层，放在 `最后一格·画（点阵 480×270）` 合成中：

- **机甲和天**：使用位置关键帧产生上下浮动，相关界面组件通过控制层跟随。
- **头发和披风**：分别使用波形变形与抽帧效果。头发固定上边、披风固定肩部一侧；摆动幅度、速度可在 AE 的效果控件中调整。
- **火苗**：通过置换图和时间重映射产生向上燃烧的变化。置换图由六张图循环使用；可调整置换图效果的「最大置换」改变运动幅度。
- **明暗**：`控制：暗几档` 滑块控制画面不同明暗档位，关键帧从第 595 帧开始设置。

### 最后一格的界面

`最后一格·界面（点阵 480×270）` 中的锁定组件、圆环、下轨、角模块、量表、读数和片名等分别组织为图层或预合成。部分元素使用形状层、蒙版、中继器、表达式和 AE 效果；例如可通过调整矩形宽度修改血条，通过移动关键帧调整元素出现时间。

读数由隐藏文字层、数字条预合成和表达式共同控制；片名与部分点阵文字使用静帧，再通过 AE 的填充、蒙版和渐变擦除控制颜色及出现方式。部分细字使用单独的 1920 × 1080 合成。

### 其他动效

- **火星**：使用六格循环素材和时间重映射表达式，按 149 BPM 的十六分节奏换格，并跟随画面明暗控制。
- **吸气框**：八个框和轨道主线使用形状层及预合成，可通过图层入点、出点调整出现时间。
- **落条故障**：横条错位、方块打乱和色差边由形状层、置换图、遮罩等 AE 效果组合实现；各步可通过定格关键帧调整。
- **状态页的剑图标**：保持原来斜放的样式，只修正像素上的歪斜和不对齐：剑身、宝石、两侧护手、剑柄和剑首对齐到同一条 45° 斜线，并沿这条线对称（27 × 32 个点，带与屏幕画面一致的点纹）。新图标在 `06 状态` 合成中盖在原图标上（第 115—156 帧）。工程包内的图标素材为 `(素材)/图层版：状态页的剑图标（照原样斜着，只修歪）/图标_01_剑_斜_屏里_108x128.png`；点阵源文件及生成脚本不在压缩包内。

## 仍使用的 PNG 序列

工程中仍有十条 PNG 序列，每条 642 张；它们并非逐元素可编辑的 AE 形状层：

| 序列 | 内容 |
| --- | --- |
| G 光晕源 | 整段使用的光晕来源 |
| T01 屏外的件·后、T10 屏外的件 | 两翼、轨道及屏外界面元素 |
| T02 屏里的画 | 屏幕内的画面 |
| T04 过场 | 逐块过场画面 |
| T05 屏里的界面件·下 | 计数条、圆环、路线及锁定组件等 |
| T06 屏里的画·中、T08 屏里的画·上 | 轨道图、画面主体及小窗等 |
| T07 屏里的界面件·中 | 警告带和合体相关界面 |
| T11 片名和名牌版 | 开头的黑带与片名 |

## 音频与工程检查

工程包包含当前使用的 21.4 秒 WAV 音频；音频末尾仅有约 10 毫秒的防爆音处理。压缩包不包含单独导出的成片视频。

整理记录显示，打包后的 58 项素材均已重新连接至包内，检查时未发现缺失；整理时还抽取了十二帧进行逐像素对照。换设备打开后，建议再次检查素材、表达式、字体和渲染设置。
